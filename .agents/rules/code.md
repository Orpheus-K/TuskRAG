# 编写清晰代码

## 收紧实现

- 命名业务：使用领域术语（知识库、版本、节、块、嵌入空间、证据）；动词命名动作；避免含糊的 Manager、Helper、通用 utils 堆积。
- 拆分职责：函数完成一个动作；模块拥有一类状态；按职责拆分，不按任意行数拆碎。
- 显式依赖：构造注入驱动与客户端；禁止隐藏全局可变状态、循环依赖和跨模块内部导入。
- 验证边界：解析外部输入、文件内容、模型输出与配置；内部使用可信类型，不逐层重复猜测和修补。
- 建模状态：使用枚举或联合类型；区分缺失、空值、失败、降级与未知结果。
- 删除冗余：清理失效分支、重复实现、注释掉的代码；兼容逻辑必须绑定真实消费者与退出条件。
- 注释原因：记录约束与取舍；不翻译代码；不留下无责任归属的 TODO。

## 拒绝无据兜底

- 暴露错误：保留原因与操作上下文；在责任边界记录一次，向上返回可判断错误。
- 禁止掩盖：不 catch 后返回成功、空集合或默认业务值；不禁用检查来“修复”失败。
- 限制重试：只重试可恢复且副作用安全的失败（网络、429、5xx）；限定次数、退避与截止时间。
- 定义降级：仅实现 [06](../../docs/06-检索与问答.md) 等文档中已定义的降级；降级必须出现在响应 `degraded` 与 trace 中。

## 选择语言

- 质量优先：每个环节使用该环节产品质量最好的技术栈；不因“统一语言”牺牲解析、检索或稳定性质量（[A02](../../docs/11-架构决策记录.md#a02)）。
- Go 为主：API、SSE、MCP、鉴权与权限、检索编排、分块、分词、任务、模型调用、审计全部用 Go 实现。
- Python 限工具：只用于 `tuskrag-parse` 解析工具（一次性 CLI）；不得新增 Python 常驻服务、数据库访问、网络访问或业务策略。新增其他 Python 工具须先在架构决策中说明 Go 无法达到同等质量的证据。

## 规范 Go

- 版本与工具：与参考项目同一 Go 版本线；gofmt、`go vet`、golangci-lint（含 depguard 层次规则）；`CGO_ENABLED=0` 静态构建。
- 结构：领域包放 `internal/`；包之间经接口协作；`httpapi`/`mcp` 只调用领域服务，不直接访问 SQL。
- 错误：显式处理并包装 error（`fmt.Errorf("…: %w", err)`）；用哨兵错误或类型错误表达可判断失败；禁止用 panic 表达业务错误。
- 取消：所有 I/O 与外部调用接收 `context.Context`；客户端断开、超时、撤权必须能终止上游模型调用与解析子进程。
- 数据库：SQL 写在 `queries/` 由 sqlc 生成；参数化；每个事务设置租户上下文；长计算与网络调用不持有事务。
- 并发：goroutine 必须有退出路径与归属；使用有界并发（semaphore/errgroup）；`go test -race` 必须通过。
- 资源：设置 `GOMEMLIMIT`；流式响应不缓存全文；子进程设置限额并在退出时清理进程组与临时目录。
- 依赖：不得引入推理框架或 cgo 依赖；新增依赖核对许可证（拒绝未经评审的 AGPL/GPL/非商用许可）、维护状态与体积。

## 规范 Python 解析工具

- 版本与工具：Python 3.13；uv 管理依赖与锁文件；ruff；mypy strict；pytest（无网络运行）。
- 边界：只读输入文件、只写指定输出目录；不读环境中的密钥；输出必须符合 `contracts/parsed-document.schema.json`。
- 职责：只“读”与报告信号，不做质量判定、出域判断或分块；失败用约定退出码表达，不输出部分结果冒充成功。
- 安全：defusedxml；限制解压大小与页数；禁止 eval/pickle 加载外部数据；禁止可变默认参数和裸 except。

## 规范 TypeScript 前端

- 固定栈：React + TypeScript（strict）+ Vite；shadcn/ui + Tailwind；禁止 Next.js/SSR。
- 组织组件：基础 UI → 通用组合 → 业务组件 → 页面；共享 UI 不访问业务 API。
- 契约：只使用由 `contracts/openapi.json` 生成的类型；用 unknown 校验 SSE 等非生成数据；禁止 any、非空断言、ts-ignore。
- 管理状态：服务端数据只放 TanStack Query；URL 能表达的放搜索参数；不复制可推导状态，不用 effect 串联可直接表达的逻辑。
- 统一视觉：复用语义 Token；Vercel 风格、亮暗主题、细边框与克制动效；禁止页面散落品牌色与重复样式。
- 保持可用：键盘、焦点、标签及加载/空/错状态；禁用按钮不能替代后端授权。
- 维护上游：追踪 shadcn/ui 来源与改动（`packages/ui/UPSTREAM.md`）；按真实复用封装。

## 复用开源

优先成熟上游；核对许可、维护、安全、体积与离线可用性；薄封装真实差异，不重造通用框架，也不引入厚框架（见 [A14](../../docs/11-架构决策记录.md#a14)）。
