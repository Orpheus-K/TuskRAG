# 验证真实行为

- 选择范围：按变更关联 [T 场景](../../docs/02-需求与验收.md#三验收场景t) 与 [V 场景](../../docs/10-评测与质量保障.md#六技术验证场景v)。
- 读取命令：检查实际 manifest、锁文件与 CI；缺少环境则记录阻塞，不声称通过。
- 验证缺陷：行为修复先复现，再以回归样例证明修复；纯文档/机械样式变更不强造业务测试。
- 覆盖风险：测试正常路径、真实边界及受影响失败模式；不写复刻实现、只匹配文字或无意义快照的测试。
- 测试契约：驱动共享行为测试；事务、RLS、队列、索引与检索 SQL 用真实 PG（`tuskrag-postgres` 镜像）验证，不用 mock 证明数据库正确性。
- 隔离模型：集成测试使用 OpenAI 兼容替身服务，可注入延迟、429、5xx、错误维度与非法输出；CI 不调用真实外部模型。
- 门禁评测：影响解析、分块、检索、重排、Prompt 的变更运行评测集并与基线对比；主指标下降超过 2 个点或越权证据数 > 0 即判定失败（[10](../../docs/10-评测与质量保障.md#三指标与门槛)）。
- 注入故障：修改任务或入库流程则测崩溃、租约过期、迟到提交与重复投递；修改权限则测撤权竞态、缓存与跨租户。
- 检查文件安全：修改解析工具则跑黄金样例与恶意样本集（zip 炸弹、XXE、畸形 PDF、伪装扩展名），并跑 Go↔解析工具跨语言测试（退出码、超限终止、schema 校验）。
- 检查并发：Go 变更运行 `go test -race`；SSE 与取消路径测试客户端断开后上游调用被终止。
- 稳定样本：固定时间、随机种子与数据集版本；用可控信号代替任意 sleep；隔离并清理测试库与临时文件。
- 检查前端：类型、组件交互、SSE 事件序列、键盘焦点与受影响页面视觉；验证 SPA 深层路由与 API 404 不回退。
- 报告证据：区分通过、失败、未运行；列命令、结果和关键限制，不以覆盖率数字代替行为证明。
