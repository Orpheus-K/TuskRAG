# 守住架构边界

- 守住单栈：PostgreSQL 是唯一事实源与检索引擎；不新增 ES、Redis、MinIO、MQ 或其他常驻服务（[A01](../../docs/11-架构决策记录.md#a01)）。
- 守住轻量：核心进程不加载模型权重；模型调用只经 `models` 模块的 OpenAI 兼容客户端（[A05](../../docs/11-架构决策记录.md#a05)）。
- 隔离解析：解析只在一次性受限子进程中运行，Markdown/TXT 使用 Go 二进制的内部解析子命令，其他已支持格式使用 `tuskrag-parse`；带内存、CPU、时间、解压上限，无网络；输出经 schema 与大小校验后才使用（[A07](../../docs/11-架构决策记录.md#a07)）。
- 固定分工：Go 核心拥有全部状态、策略与读路径；Python 工具不访问数据库、网络或密钥，不做业务判断（[A02](../../docs/11-架构决策记录.md#a02)）。
- 隔离所有权：模块通过公开服务接口协作；禁止直接改写其他模块的表、状态或文件。
- 约束驱动：Lexical、Vector、FileStore、Queue 驱动遵守同一行为契约；能力缺失即拒绝启动或显式声明降级，不静默切换路径。
- 原子推进：版本切换、ACL 变更与任务入队在同一短事务内完成；网络调用与长计算放在事务外。
- 防止重放：任务校验租约世代与幂等键；嵌入按 `(chunk_id, space_id)` 幂等写入；迟到结果拒绝提交。
- 隔离租户：每个事务设置 `tuskrag.tenant_id`；应用角色无 BYPASSRLS；未设置即失败。
- 过滤证据：召回 SQL 内预过滤 `access_tags`；出库前按当前 ACL 复核；不可见对象表现为不存在，不泄露标题与计数。
- 控制出域：所有模型调用前检查知识库出域策略与提供方 locality；违规直接失败并审计（[A16](../../docs/11-架构决策记录.md#a16)）。
- 隔离输入：文档内容与模型输出均为不可信输入；证据在 Prompt 中作为数据块；Agentic 工具只读。
- 区分结果：接口区分 ok、no_match、degraded 与错误；禁止以空结果表示失败。
- 最小采集：日志与审计保留标识、版本、状态与摘要；禁止记录正文、完整 Prompt、模型输出全文与密钥。
- 契约先行：API 变更同步 `contracts/` 生成物与前端客户端；解析输出变更同步 `parsed-document.schema.json` 与 `schema_version`；CI 校验一致。
