2026-11-06 工作树；R11/R13、M1。交付 `/kb/$kbId/eval` 报告页面，复用已生成契约及报告存取/列表接口；未实现评测集编辑、两次报告对比及批量运行。

## 交付行为

- owner/admin 从知识库文档页进入。列表显示数据集、模型标记、模式、来源和汇总指标，游标写入 URL；新导入后刷新首页并打开报告。
- 导入非空、最大 8 MiB JSON；客户端校验结构后发送 CSRF 请求，服务端仍负责完整一致性、证据权限和去重校验。外部导入、模型替身及真实模型标记明确区分，不将导入成功当作质量证明。
- 报告显示 Recall@20、Hit@5、MRR@10、nDCG@10、配置/数据集摘要和阶段 p50/p95。逐题每页 20 条，展开查看融合候选、最终顺序、位置标识、降级与耗时；保留无答案题 null 指标，不显示成零。报告无问题/正文数据，不虚构缺失内容、引用或拒答指标。
- 题号页码、报告摘要、列表游标使用 URL，深层链接刷新可恢复。数据使用租户/用户/知识库隔离的 Query key；请求取消信号传给读取接口。后台请求失去权限时隐藏既有列表与详情，显示错误和刷新入口；失效报告可返回列表。归档只读，viewer/editor 不请求报告接口。
- 客户端拒绝非法列表顺序/游标、错配摘要、非法指标/证据位置和报告结构；不把错误转换为空报告。
