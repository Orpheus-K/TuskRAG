# 服务端运行对比页面

2026-11-06 工作树；R11/R13、T12（检索指标部分）、M1。

交付 `/kb/$kbId/eval/run-compare`，从运行历史进入。列表保留全部可见状态，仅有成功结果的运行能设为基线或当前；选择、列表游标、逐题偏移保存在 URL。支持交换方向、清空、刷新、每页 20 题，以及汇总和逐题差值、两百分点门禁、证据与耗时差异。
