# 固定题集修订运行对照

2026-11-06 工作树；R11/T12、M1。交付 `RunSet` 与离线 `eval run-set` 入口，后续后台任务可复用同一执行核心。任务调度、服务端结果落库和控制台运行尚未实现。

## 行为

指定正数题集 ID/修订，读取并校验定义摘要；将期望文档/节/页直接传给现有 Score，不转成丢失位置的文档 key。原有 Dataset 与题集入口共用逐题检索、模式投影、重排开关、越权检测、指标及耗时汇总，原 Dataset 摘要与配置摘要生成方式不变。开始和结束复核固定修订的权限及目标，执行网络请求时不持有题集事务。

取消、查询错误、缺失 trace、越权候选、重排降级、结束复核失败均不得标为 passed；题集失败清空逐题证据、汇总和延迟，避免撤权后发布部分结果。报告只有题号、证据标识与指标，不包含问题或参考答案。详细 CLI 参数和文档/模型版本边界见[评测说明](../../tests/eval/README.md#已保存题集的固定修订运行)。
