# 文档版本发布对照（2026-10-28）

- 范围：R05、R13、R20、T04、T14；隔离 PostgreSQL 17.9、pgvector 0.8.1、pg_search 0.22.6，合成文档与向量。测试创建并删除本次专用数据库。
- 对照：发布前版本停在 `indexing`、当前块和向量均为 0；发布后版本为 `ready`、任务为 `succeeded`，当前块和向量各 2 条。新版本事务未提交或回滚时，另一连接仍命中旧版本；提交后词法和向量各只命中新版本。异租户命中数为 0。
- 围栏：缺少索引、缺失或被篡改的暂存数据、损坏的旧版本、审计失败、租约过期和事务内租约到期均不发布；检查点事务、无围栏事务和其他任务的完成事务不能执行发布效果。较新版本先完成后，较旧任务不能覆盖当前版本。
- 事务：旧版本变为 `superseded`，其清理任务与新版本状态、当前指针、块向量标记、审计及入库任务完成一并提交；注入错误时一并回滚。索引管理与发布使用非阻塞的事务级协调锁，避免并发建索引时相互等待快照。
- 复现：为本机独立 `tuskrag_test_` 数据库设置 `TUSKRAG_TEST_ADMIN_URL`、`TUSKRAG_TEST_APP_URL`、`TUSKRAG_TEST_MIGRATOR_URL`，在 `services/core` 执行 `go test -p 1 -count=1 -run '^TestPublicationAtomicSwitchPostgres$' -v ./internal/ingest`。测试要求管理员具备创建测试数据库和扩展的权限，并只清理本次创建的数据库。
- 限制：版本由测试直接构造，向量为合成数据；重新上传入口、worker、清理执行、真实模型及完整检索尚未接入。未测检索准确率、吞吐或延迟，不能据此宣称 T04/T14 端到端验收通过。
