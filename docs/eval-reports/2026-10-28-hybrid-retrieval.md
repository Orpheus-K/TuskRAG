# 混合召回对照（2026-10-28）

关联 R06、R13、R15、R16、T05、T08、T09；以下为开发验证，不等于完整验收。

## 方法与结果

使用本机隔离 PostgreSQL 17、pgvector 0.8.1、pg_search 0.22.6、临时数据库和合成文档。模型为本机 HTTP 替身，向量与 token 用量均为测试数据；没有客户文档或真实模型参与。

| 场景 | 接入前 | 接入后 |
|---|---|---|
| 两个已发布块，查询包含首块关键词 | 无检索入口 | 两块经向量召回，关键词块同时经 BM25 召回并以 RRF 排名第一 |
| 租户交替查询 | 无检索入口 | 两租户各有独立知识库与文档，在同一连接交替查询 12 轮，越权证据数为 0 |
| 检索期间变更文档 ACL、标签或撤销成员 | 无检索入口 | 变更提交后出库复核不返回该文档；撤销成员返回不可见错误 |
| 模型 503、用量缺失或不一致 | 无检索入口 | 显式报错，无证据结果；出域拒绝时不发送模型请求并写审计 |
| 检索审计写入失败 | 无检索入口 | 返回错误，不返回证据；成功审计只记录查询摘要、长度与数量 |

查询支持单知识库、标签、类型和更新时间过滤；词法与向量候选在 SQL 中过滤并以 RRF 融合，响应注明 `score_kind=rrf` 和 `degraded=["rerank"]`。进程测试在 Linux `all` 模式下完成真实登录、模拟模型调用及检索；桌面和 375 px 移动视口均通过浏览器布局检查。

本测试的两行数据下，默认规划器选择主键扫描与排序；关闭顺序扫描与排序后，`EXPLAIN` 可使用 BM25 和 HNSW 索引，证明查询可匹配索引，不代表真实规模下的选择、延迟或召回率。检索事务强制自定义计划，并在候选出库前重查当前成员、文档、版本及过滤条件。

## 限制

- 当前只支持继承知识库权限的文档和单知识库；受限文档不返回，完整文档 ACL、跨库检索及连接池代理仍待实现或验证。
- 重排、父节扩展、阈值、问答和检索调试台尚未实现；显式请求重排或父节扩展会报错，不能把本次结果当作重排完成。
- 本地模型替身使用同一 BGE-M3 计数器，不能证明真实嵌入模型兼容；代表性数据集上的 Recall、MRR、nDCG、中文检索质量和性能均未测。
- 标签和类型在候选阶段使用块上的冗余字段，出库时复核文档当前字段；标签变更后的索引刷新尚未实现，可能漏召回。
