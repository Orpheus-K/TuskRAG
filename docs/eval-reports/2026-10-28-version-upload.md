# 文档版本更新对照（2026-10-28）

关联 R02、R05、T04、A07。结果为隔离开发验证，非完整产品验收。

此前发布与清理阶段已有数据库测试，但没有重新上传入口。现在编辑者可以通过 REST 或控制台向同一文档上传同格式文件，新版本保留原文档标题并进入队列；处理完成前不改变当前版本。相同原件与不同表头确认决定可以创建新版本，同一文档相同原件与决定不会重复创建；其他文档的重复内容仍须显式允许。旧版幂等请求的摘要保持兼容。

在本机隔离 PostgreSQL 17、pgvector 0.8.1、pg_search 0.22.6 和本地模型替身上，启动真实 Linux `all` 工作进程，经 HTTP 上传 Markdown 修订版，并在向量模型调用处阻塞：检索只返回旧版本；释放后检索只返回新版本。随后上传不支持的修订版，处理明确失败，检索仍返回已生效版本。结果未使用客户数据或真实模型。

真实数据库测试覆盖同一版本并发去重、请求重放与冲突、同内容改变表头决定、跨文档重复、文件类型不符、跨租户及查看者拒绝、上传期间成员撤销后的复核和未提交原件清理。独立测试库从迁移 14 升级到 16，验证旧版本保留默认未确认状态、确认决定不可修改，及新的版本唯一约束。HTTP 在读取 multipart 正文前检查目标文档权限。控制台组件测试和 375 px 浏览器测试覆盖选择文档、确认表头和提交。

仅覆盖受支持的格式、继承知识库权限的文档和合成数据；文档删除、完整 ACL、真实模型、客户数据、代表性检索指标与完整 T04 并发验收仍待验证。
