# 文档软删除与清理对照（2026-10-28）

关联 R05、R13、R15、T04。测试使用本机隔离 PostgreSQL 17、pgvector 0.8.1、pg_search 0.22.6、合成文件与本地模型替身，不使用客户数据或线上服务。

此前只能清理被新版本替代的版本，没有文档删除入口。现在编辑者可在 REST 和控制台删除继承知识库权限的文档：事务内隐藏块和向量、清空当前版本指针、记录软删除与审计，并为各版本安排后台清理。每次最多 10,000 个版本；文档软删除记录保留。清理任务使用租约围栏，先取消目标版本仍活动的入库任务，再移除原件、解析产物、节、块和向量；原件删除失败可重试。

真实 Linux `all` 进程通过 HTTP 删除含生效版与失败版的文档：响应 202 后检索不返回该文档，后台最终清除全部版本、块与原件。真实数据库并发测试在模型调用中删除文档，通过第二个工作进程取消入库并清理两版；删除期间的新版本上传被拒绝且临时原件被清理。检索出库复核与并发软删除交错时，越权/已删除证据数为 0。审计失败使删除、隐藏与清理任务全部回滚；查看者、跨租户和错误任务载荷被拒绝。

控制台组件测试验证取消确认不会发送删除请求，确认后清除已显示的检索内容；375 px 浏览器测试验证确认与提交。删除响应仅代表已隐藏并入队，清理完成状态、死信手动重试、文档 ACL 与完整 T04 并发验收仍待实现或验证。
