# 知识库检索配置编辑验收

2026-11-06 工作树；M1 小功能，关联 R01/R06/R13/R15、A09。基于[配置存取](2026-11-06-kb-config.md)与[配置消费](2026-11-06-config-consumption.md)。不代表 M0/M1 整体完成。

## 交付

控制台 owner/admin 按需读取检索默认值，按服务端 ETag 保存返回条数及重排提供方、模型、候选数、阈值和降级设置。零阈值保留，关闭重排时省略整份 reranker。保存后刷新相关检索查询。409 保留草稿并禁止再次提交，显式刷新成功后采用新修订；刷新失败或折叠面板不丢草稿。归档只读，401/403/知识库 404 隐藏配置。无效提供方单独返回 404 provider_not_found，保留可编辑表单，仍不透露异租户提供方。

知识库管理员不一定有平台管理权限，故采用提供方编号输入，不依赖平台提供方列表。客户端验证响应结构、ETag 与递增修订，拒绝伪成功。
