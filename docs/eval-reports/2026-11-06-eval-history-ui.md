# 控制台运行历史

2026-11-06 工作树；R11/R13、T12、M1。

交付 `/kb/$kbId/eval/history`，从报告、题集和运行详情进入。展示可见运行的状态、模式、题集修订、尝试次数、最近失败码、创建时间和结果可用性。按服务端 ID 游标分页，URL 保存游标；打开详情传递运行 ID 和固定修订，浏览器返回保留原页。历史页显式刷新，持续状态跟踪沿用详情页轮询。

归档允许历史浏览；非管理员不请求列表。撤权和不可见错误隐藏历史，其他读取错误也隐藏旧缓存和下一页入口，不把错误当空页。客户端复用运行状态校验，并验证严格升序、页大小及下一页游标；非法响应显式失败。
