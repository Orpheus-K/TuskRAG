# 控制台评测运行

2026-11-06 工作树，R11/R13、T12、M1。

从题集编辑页打开已保存修订的运行页 `/kb/$kbId/eval/runs`，选择 lexical/vector/rrf/rerank 后入队。请求只含题集、修订和模式；会话 CSRF 与稳定幂等键随请求发送。创建失败锁定模式，原样重试保留原始输入及键，明确提示配置重排模型或归档错误。页面内稳定重试不等于刷新前未确认请求的持久恢复。

成功后运行编号与逐题页码进入 URL，刷新直接读取已有运行。queued/running 每两秒轮询，succeeded/failed/dead/cancelled 停止；状态错误停止轮询并提供显式刷新。后台可重试失败实际回到 queued；failed 为终态。成功才读取 executed 结果，复用指标、耗时及逐题证据展示，来源与 imported 区分。权限或证据不可用时隐藏整个页面内容；状态/结果错误不展示旧缓存报告。归档允许读取但不能启动；普通成员不发起运行请求。
