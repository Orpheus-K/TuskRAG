# 报告对比服务验收

2026-11-06 工作树；R11/R13、T12 检索指标部分、M1。交付领域比较、授权服务、分页 GET 接口与生成契约。对比页面控件尚未接入，引用和拒答等生成指标仍未实现，不代表完整 T12/M1 通过。

## 行为

完整报告按题号对齐，检查数据集摘要、检索模式、模型类别、题数、有答案题数、题号集合和每题答案属性。行顺序允许不同；仅无答案题的报告不进入检索比较。返回基线与当前值、当前减基线的差值，以及每题证据、降级和耗时原值。无答案题差值为 null。任一汇总指标下降超过两百分点，gate 为 regressed，比较仍成功返回；不会把回归当作无结果。

CLI compare 复用同一门禁和完整题集校验；已提交的仅汇总 CI 基线仍保留汇总口径。报告存储比较在同一租户/知识库事务内读取两份报告，先检查成员，再合并全部证据加锁复核，之后才计算和分页。页外不可见证据同样拒绝比较，防止通过汇总差值泄露。接口参数和边界见 [13](../13-接口契约概要.md)。
