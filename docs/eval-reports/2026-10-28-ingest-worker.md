# 入库工作进程对照（2026-10-28）

关联 R02—R05、R13、R16、R20、T14；以下是开发验证，不等同完整产品验收。

## 方法

在本机隔离 PostgreSQL 17、pgvector 0.8.1、pg_search 0.22.6 的临时数据库中运行合成数据。模型使用本机 HTTP 替身，依据同一固定 BGE-M3 计数器报告 token 用量；未调用真实模型或使用客户文档。Linux 进程测试使用真实 bubblewrap、委派的 cgroup v2 和 Python 解析工具。

| 场景 | 接入前 | 接入后 |
|---|---|---|
| Markdown 入库 | worker 角色拒绝启动 | 单文档经真实启动、解析、嵌入、发布后就绪，产生 1 个当前块和 1 个当前向量 |
| Markdown 表格与模型暂时不可用 | 不处理任务 | 合成文档产生 2 个当前块和 2 个当前向量，首次模型 503 后第二次完成；其中 1 块为表格 |
| CSV 表格 | 不处理任务 | 沙箱解析成功；未确认表头时显式失败，用户确认后可入库，见[表头对照](2026-10-28-table-header-confirmation.md) |
| 低质量文本 | 不处理任务 | 标记 `quality_review`，模型调用数为 0 |
| 原件缺失或篡改 | 不处理任务 | 发现缺失、篡改并显式失败 |
| 模型调用期间强杀进程 | 不处理任务 | 强杀后推进该测试租约到过期，重启认领第 2 次并完成；当前块和向量各 1 个 |
| 租户隔离 | 不处理任务 | 上述发布样例中，异租户可见块数为 0 |

索引在模型调用后消失的故障测试会重试，索引恢复后复用已写向量；旧版本清理由同一工作进程分发。多租户任务按配置列表轮询，未支持的任务类型不认领。

## 限制

- 逐表表头预览、页级报告持久化、VLM、用户重试、重新上传和文档删除尚未接入；质量门目前直接失败，不生成部分可用版本。
- 原生解析仅覆盖 Markdown/TXT；Python 工具仅覆盖已实现的 CSV/DOCX/XLSX 子集。CSV 等未确认表头时不能发布；数字 PDF 及其他格式尚未完成。
- 模型替身使用相同计数器，不代表真实模型的 token 用量一致；真实服务、代表性知识库、检索准确率和性能均未测。
- `worker` 和 `all` 在 Linux 测试环境中启动并正常停止；强杀实验手动推进测试任务的租约，不代表等待自然到期的实测时长。Windows 隔离和生产容器安全配置尚未完成。
