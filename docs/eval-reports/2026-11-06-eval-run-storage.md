## 边界

迁移 23 新建不可变 eval_run，引用指定题集历史修订与同租户 job。保存题集摘要、RunConfig（主体、知识库、允许文档范围、显式重排参数、模型标识、配置绑定）、配置摘要、模式和创建时间；任务 payload 仅含 run_id，不复制问题或参考答案。状态继续由 job 维护，不新增平行状态机。应用角色只能 SELECT/INSERT；表强制 RLS。

Create 必须带非空、至多 128 个可打印 ASCII 字符的幂等键。先验证主体/知识库绑定、固定题集修订及允许文档范围，按文档 ID 顺序锁完整范围，再锁知识库、成员和期望位置；新运行要求知识库 active、owner/admin、当前配置绑定仍匹配。幂等预留、队列入队、运行记录、审计在同一事务提交，不执行模型调用。

相同主体/知识库/键和相同请求返回原始运行及 job；题集头或配置随后变化不替换原始快照，终态任务也不会因创建重试而重新入队。不同内容冲突。重试仍检查当前权限、期望位置和知识库归档状态。Get 可读取归档记录，但所有允许文档及期望位置必须当前可见；失效则整份拒绝。

运行配置 JSON 上限 1 MiB、允许文档 ID 至多 10000 且不得重复；所有期望文档必须属于该范围。服务端模型标识与范围必须由后续可信传输层选择，当前内部接口的 model_kind 不是模型来源证明。执行阶段仍须按任务创建者重新授权，租约完成事务复核全部实际返回证据。
