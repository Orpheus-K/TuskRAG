## 交付

POST `/api/v1/kbs/{kb}/eval-runs` 接受固定题集 ID、修订及模式。服务端生成当前主体、完整可见文档范围、嵌入/检索配置快照和模型标签；创建期间不调用模型。运行、队列、审计和幂等结果同事务提交。接口契约集中在 [13](../13-接口契约概要.md)。

幂等预留先于领域锁，避免同键并发与知识库/文档锁倒序。原始请求决定幂等摘要；重试检查原范围的当前权限，然后返回原运行，配置更新或新增文档不会产生第二个任务。保存的 rerank 配置强制禁用降级，缺失配置显式失败。
