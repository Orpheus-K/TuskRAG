# 08 前端架构与交互

## 一、基线（沿用 agent-project 的前端规范）

| 项 | 选择 | 来源 |
|---|---|---|
| 框架 | React 19 + TypeScript（strict）+ Vite；客户端 SPA | 参考项目规范；禁止 Next.js / SSR / 常驻 Node |
| 组件 | shadcn/ui（new-york 风格，源码纳入 `packages/ui`，记录 UPSTREAM 与许可证） | 同上 |
| 样式 | Tailwind CSS 4 + 语义化 CSS 变量 Token（oklch 中性色），亮暗主题 | 同上 |
| 视觉 | Vercel 风格：黑白灰、细边框、克制阴影与动效、清晰排版与信息密度 | 同上 |
| 工程 | pnpm workspace；Biome（格式与检查）；dependency-cruiser（边界）；Vitest + Testing Library；Playwright | 同上 |
| 交付 | 静态产物由 Go `embed` 打进核心二进制；SPA 深层路由回退到 `index.html`，但 `/api`、`/mcp`、静态资源 404 不得回退 | 同上（与参考项目一致） |

在参考规范之上新增的依赖（引入前核对许可、维护与体积）：

| 需求 | 选择 | 理由 |
|---|---|---|
| 路由 | TanStack Router（文件外的代码式路由，类型安全搜索参数） | 检索调试台、文档列表大量依赖 URL 状态 |
| 服务端数据 | TanStack Query | 缓存、失效、轮询入库进度 |
| 表格 | TanStack Table + shadcn Data Table 组合 | 文档、任务、审计列表 |
| 表单 | react-hook-form + zod | 配置表单与校验 |
| API 类型 | openapi-typescript + openapi-fetch（`packages/api-client`） | 单一契约来源，禁止手写重复类型 |
| SSE | `fetch` + eventsource-parser | 需要携带 CSRF 头与 POST 体，原生 EventSource 不满足 |
| Markdown | react-markdown + remark-gfm（禁用原始 HTML） | 回答与解析预览 |
| PDF 预览 | pdf.js（按需懒加载） | 引用定位到页 |
| 图标 | lucide-react | shadcn 默认 |

## 二、分层与边界

```text
packages/ui          基础 UI（Button、Input、Dialog、Table…）+ 通用组合（EmptyState、ConfirmDialog、
                     DataTableToolbar、StatusBadge、CodeBlock）+ 主题 Token；不访问业务 API
packages/api-client  生成的类型 + 薄请求函数 + SSE 解析；不依赖 UI
apps/web/src
  routes/            页面：组合与数据协调
  features/<域>/     业务组件与 hooks：kb、documents、search、chat、eval、access、admin
  lib/               应用级工具（query client、错误映射、权限展示辅助）
```

- dependency-cruiser 规则：`packages/*` 不导入 `apps/*`；`ui` 不导入 `api-client`；应用只通过包的 `exports` 导入；禁止循环。
- 状态：服务端数据只在 TanStack Query 中；URL 能表达的（筛选、分页、选中项）放在搜索参数；只有纯临时交互用组件状态；不复制可推导状态。
- 权限：前端按 `/api/me` 返回的能力隐藏或禁用操作，仅为体验；所有授权以后端为准，403/404 有明确界面。

## 三、页面与路由

| 路由 | 页面 | 关键内容 |
|---|---|---|
| `/login` | 登录 | OIDC 按钮；本地账号入口（启用时） |
| `/` | 工作台 | 我可访问的知识库、最近会话、入库中任务 |
| `/kb` | 知识库列表 | 文档数、块数、状态、嵌入空间、出域策略徽标 |
| `/kb/$kbId/documents` | 文档 | 上传（拖拽、批量、进度）、状态筛选、版本、标签、ACL 标识 |
| `/kb/$kbId/documents/$docId` | 文档详情 | 四个标签页：原件预览 / 解析 Markdown / 节树与块 / 解析报告（页级质量、VLM 页、警告） |
| `/kb/$kbId/search` | 检索调试台 | 查询、过滤、参数（TopK、权重、阈值）；并列展示 BM25、向量、RRF、重排四列排名与分数、耗时、degraded |
| `/kb/$kbId/settings` | 设置 | 分块与检索参数（带修订历史）、嵌入空间与重建、出域策略、成员与角色 |
| `/kb/$kbId/eval` | 评测 | 评测集、用例编辑、运行、两次运行指标对比与逐题差异 |
| `/chat`、`/chat/$conversationId` | 问答 | 选择知识库范围、模式（标准/Agentic）、流式回答、引用 |
| `/access` | 接入 | API Key 管理；MCP 配置片段（复制）；REST 示例 |
| `/admin/*` | 管理 | 身份源、用户与组、模型提供方与连通性测试、审计日志、系统状态（版本、迁移、驱动、队列、资源） |

## 四、关键交互

### 4.1 问答与引用

- 流式渲染：收到 `retrieval` 事件即显示“已检索 n 条证据”可展开列表；`delta` 增量渲染；`citations` 到达后把 `[n]` 渲染为引用标记。
- 引用标记：悬停显示标题路径、页码与片段；点击在右侧面板打开原文并定位到页/节，高亮片段。
- 状态必须可见：拒答、`unsupported`（无有效引用）、`degraded`（未重排/仅关键词）、`truncated`（Agentic 超限）、错误（区分“模型不可用”与“无权限”）。
- 反馈：👍/👎 + 可选原因（不相关、事实错误、引用错误、遗漏）+ 正确答案/文档建议，进入评测待审池。
- 停止生成：中止请求；服务端取消上游调用。

### 4.2 入库进度

- 文档列表对非终态文档每 3 s 轮询（或 SSE 订阅任务事件，M4 视需要）；终态停止轮询。
- 失败显示 `failure_code` 的可读说明与操作（重试、查看报告、联系管理员），不显示原始堆栈。

### 4.3 检索调试台（“准”的主工具）

- 四列对比（BM25 / 向量 / RRF / 重排），同一块在各列的位置以连线或高亮关联。
- 每条候选可展开：`search_text`、标题路径、页码、所属节，一键“设为期望答案”加入评测集。
- 参数改动不落库，只影响本次调试；“保存为知识库配置”生成新的配置修订。

## 五、可用性与质量

- 键盘：所有操作可 Tab 达到；对话框焦点陷阱与返回；快捷键 `/` 聚焦搜索、`Esc` 关闭面板。
- 可访问名称：图标按钮带 `aria-label`；状态区域用 `role="status"`；不只依赖颜色表达状态。
- 必备状态：加载骨架、空状态（带下一步操作）、错误状态（可重试）。
- 国际化：v1 仅中文界面，但文案集中管理（便于后续 i18n），时间按浏览器时区显示。
- 性能：路由级代码分割；pdf.js、Markdown 渲染懒加载；首屏 JS gzip ≤ 250 KB（目标）。
