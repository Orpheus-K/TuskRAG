# 04 数据模型与存储

## 一、原则

1. PostgreSQL 是唯一事实源：业务数据、索引、任务、审计都在同一库，备份一次即一致（文件除外，见第七节）。
2. 所有业务表带 `tenant_id`，启用 RLS；应用连接每个事务执行 `SET LOCAL tuskrag.tenant_id = ...`。
3. 检索热路径需要的过滤字段（租户、知识库、访问标签、是否当前版本）**反范式化到 chunk 与 chunk_vector**，让过滤在索引扫描内完成，避免先召回后过滤导致的召回不足。
4. 版本不可变：解析产物绑定 `document_version`；切换只改指针与标志位。
5. 迁移只向前；破坏性变更分“扩展 → 回填 → 切换 → 收缩”多步发布。
6. 变更文档版本指针、块可见性或访问标签时，同一事务先锁定对应 `document` 行，再修改块和向量；与发布阶段采用同一锁顺序。当前版本只能指向 `ready/partial`，进入 `purging` 的版本不得恢复；数据库触发器与就绪检查共同约束这两条规则。

## 二、实体关系

迁移 26/27 已实现 `chat_model`、`conversation`、`answer_message`、`answer_feedback`。会话归用户所有并固定知识库/模型，消息保存有界正文、问题、源块及版本引用、生成状态/用量/耗时；证据正文不复制入会话。一个会话最多 50 轮，部分生成不可作为完成历史读取。反馈以消息为键保存最新点赞/点踩及待审纠错。四表均强制租户 RLS；用户隔离及当前证据复核由领域事务执行。协议与恢复规则见 [13](13-接口契约概要.md#二sse-事件)。

```text
tenant ─┬─ app_user ─┬─ group_member ── user_group
        │            └─ api_key
        ├─ model_provider ── embedding_space
        └─ knowledge_base ─┬─ kb_member (user|group, role)
                           ├─ kb_config_revision
                           ├─ document ─┬─ document_acl (user|group, allow)
                           │            └─ document_version ─┬─ parse_page (质量报告)
                           │                                 ├─ section (树)
                           │                                 └─ chunk ── chunk_vector (每嵌入空间一行)
                           ├─ conversation ── message ── citation / feedback
                           └─ eval_set ── eval_set_revision (cases JSONB) ;  eval_run ── eval_result
job（任务队列）   audit_log（按月分区）   query_embedding_cache（UNLOGGED）
```

## 三、核心表（设计草图，最终以迁移文件为准）

迁移 25 的 `embedding_rebuild` 保存重建 job_id、知识库、旧空间与配置修订、目标空间及提供方/模型/维度/归一化/距离快照、创建者和时间。应用角色只可 SELECT/INSERT，强制租户 RLS，各外键绑定租户。状态、尝试次数与失败码直接取 `job`，不复制状态机。领域创建要求 owner/admin、活动知识库、精确源配置修订及同租户 cosine 目标；检查当前出域限制。`pending_space_id` 预留、不可变记录、reembed 入队、幂等结果与审计同事务提交；同知识库一次只预留一个目标。创建不改变当前空间与 config_revision，不调用模型。幂等重试按原请求返回原任务，并重新检查当前权限和归档状态；拒绝出域的审计独立于创建成功，不能留下半成品幂等预留。

领域服务支持取消、失败与耗尽租约清理：任务和匹配的 pending 指针同事务更新；可重试失败保留预留，终态释放。取消要求当前 owner/admin，可用于归档知识库；审计失败完整回滚。过期清理只能由队列的耗尽恢复事务调用，迟到租约不能释放后续重建。锁顺序为任务→知识库→成员，与后台完成路径保持一致。专用 Target/resolver 绑定当前租约，每次解析模型范围时复核创建者当前 owner/admin、活动状态、源空间/修订、pending 指针及不可变目标模型快照，并读取当前租户/知识库出域策略交给 models 客户端执行出域判断；现有活动空间 resolver 不接受 pending 目标。ingest.RebuildVectors 已提供当前 ready 文档的分页批次读取与幂等目标向量写入：任务→文档→知识库→成员锁序，批次绑定任务、版本、原始 search_text 与块标识；写入复核快照和当前权限，复用 halfvec 校验，新旧空间向量并存且不切换活动绑定。RebuildEmbedding 已提供独立模型批次编排：有界遍历当前文档和块，复用 models 客户端固定运行时快照、目标分词探测与逐批用量校验；每次正文发送前复核精确批次，返回后再次验证并幂等写入。Run 不完成任务、不切换空间；并发发布产生的覆盖变化必须由最终事务判定。Completion 已连接索引定义/就绪检查、全部当前文档和块覆盖校验以及原子切换：必须在匹配租约的 Complete 事务内，锁知识库后检查全部当前证据与目标向量，拒绝缺失/错误标签/非当前/维度或归一化不符及多余当前行；CAS 切换空间、递增源配置修订、释放 pending、审计与 job 成功同事务。持有知识库锁时不再申请文档锁；既有发布/删除在改变当前证据前取得同一知识库锁。覆盖查询只投影标识与状态，不加载全文。生产 worker 已领取 reembed，Prepare 连接模型批次与完成效果，失败和耗尽回调调用领域清理。模型临时故障、索引不可用及 rebuild_incomplete（当前覆盖变化）按队列策略有限重试；永久失败或尝试耗尽与 pending 释放同事务。创建/查询/取消 HTTP 已接入，契约见 [13](13-接口契约概要.md)；控制台仍待实现。排队记录不代表重建已成功，最终结果以任务终态和实际绑定为准。后续执行必须复核目标快照、当前权限及出域策略，切换前确认当前版本块覆盖完整并满足租约，不能仅凭任务状态切换；索引 DDL 继续由既有迁移角色命令负责（A04）。

迁移 22 的 `eval_set` 保存当前修订号，`eval_set_revision` 保存整份不可变题集定义、SHA-256、创建者与时间。用例作为定义内 `cases` 保存，不单独建立 `eval_case` 表：题集以完整修订进行并发控制与历史绑定，避免分行编辑混合不同版本。头指针通过延迟外键保证提交时对应修订存在；两表强制租户 RLS，应用角色不能修改或删除历史定义。内容上限与授权语义见 [13](13-接口契约概要.md)。

迁移 23 的 `eval_run` 保存不可变题集 ID/修订/摘要、完整 RunConfig 与配置摘要、模式、主体、时间及唯一 job_id。任务状态以 `job` 为准，不复制状态机；队列 payload 仅含 run_id。创建时完整允许文档范围和题集目标均按当前权限复核，配置绑定必须仍有效；快照、入队、幂等记录和审计同事务提交。应用角色仅可 SELECT/INSERT，强制租户 RLS，job 外键包含 tenant_id。

迁移 24 的 `eval_run_result` 每个运行最多保存一份不可变成功报告和摘要，与 `job=succeeded`、完成审计在同一个有效租约事务中提交。worker 已领取 eval_run，按记录中的创建者执行，模型调用不持有事务；完成前复核配置绑定、题集目标、完整允许范围及实际返回证据。取消、租约失效、失败或撤权不保存部分报告。读取时重新检查当前读取者和证据；领域返回来源 executed，外部导入仍只进入 eval_report。运行状态/结果 GET 已接入，见 [13](13-接口契约概要.md)；HTTP 创建及控制台固定修订运行、状态轮询与结果展示已接入，queued 不代表已执行。

当前迁移已建立 `section`、`chunk`、`chunk_vector` 与 `ingest_plan`，强制租户 RLS，并约束文档版本归属、页范围、块大小和向量维度；`audit_log.details` 为对象型 JSON，用于保存受控的审计上下文。暂存服务校验任务、租约、父节顺序、嵌入空间配置和计划摘要，事务内创建非当前节、块与向量；数据库本身尚未禁止所有节树环。工作进程已接入发布与清理阶段；单知识库混合召回和出库权限复核已接入，完整文档 ACL 与重排未完成。证据见[入库对照](eval-reports/2026-10-28-ingest-worker.md)、[发布对照](eval-reports/2026-10-28-version-publication.md)、[清理对照](eval-reports/2026-10-28-version-purge.md)和[召回对照](eval-reports/2026-10-28-hybrid-retrieval.md)。

```sql
-- 知识库：绑定当前嵌入空间与配置版本
CREATE TABLE knowledge_base (
  id               bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  tenant_id        bigint NOT NULL REFERENCES tenant(id),
  name             text   NOT NULL,
  embedding_space_id bigint NOT NULL REFERENCES embedding_space(id),
  pending_space_id bigint REFERENCES embedding_space(id),  -- 重建中的新空间（T13）
  config_revision  int    NOT NULL,                        -- 指向 kb_config_revision
  egress_policy    text   NOT NULL CHECK (egress_policy IN ('deny','internal_only','allow')),
  status           text   NOT NULL CHECK (status IN ('active','archived')),
  created_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE (tenant_id, name)
);

CREATE TABLE embedding_space (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  tenant_id bigint NOT NULL,
  provider_id bigint NOT NULL REFERENCES model_provider(id),
  model text NOT NULL, dims int NOT NULL CHECK (dims BETWEEN 64 AND 4000),
  normalized boolean NOT NULL, distance text NOT NULL CHECK (distance IN ('cosine','ip')),
  index_name text                                   -- 对应的部分 HNSW 索引
);

CREATE TABLE document (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  tenant_id bigint NOT NULL, kb_id bigint NOT NULL REFERENCES knowledge_base(id),
  title text NOT NULL, source_uri text, mime text NOT NULL,
  current_version_id bigint,                         -- 检索只认它
  acl_mode text NOT NULL CHECK (acl_mode IN ('inherit_kb','restricted')),
  acl_revision int NOT NULL DEFAULT 1,               -- ACL 每次变化 +1，用于复核与缓存失效
  tags text[] NOT NULL DEFAULT '{}',
  deleted_at timestamptz
);

CREATE TABLE document_version (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  tenant_id bigint NOT NULL, document_id bigint NOT NULL REFERENCES document(id),
  content_sha256 bytea NOT NULL, byte_size bigint NOT NULL, file_key text NOT NULL,
  status text NOT NULL CHECK (status IN
    ('queued','parsing','embedding','indexing','ready','partial','failed','superseded','purging')),
  failure_code text, failure_detail text,           -- 显式失败原因（不含正文）
  parser_profile text NOT NULL,                      -- 解析器与版本，便于重放
  confirm_first_row_headers boolean NOT NULL DEFAULT false, -- 上传者对所有表格首行的确认，版本内不可更改
  page_count int, vlm_page_count int NOT NULL DEFAULT 0,
  created_by bigint NOT NULL, created_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE (tenant_id, document_id, content_sha256, confirm_first_row_headers)
);

-- 节：标题树；父块即节正文（必要时截断到上限）
CREATE TABLE section (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  tenant_id bigint NOT NULL, version_id bigint NOT NULL REFERENCES document_version(id),
  parent_section_id bigint REFERENCES section(id),
  ordinal int NOT NULL, level smallint NOT NULL,
  heading text NOT NULL, heading_path text[] NOT NULL,
  page_start int, page_end int,
  body_md text NOT NULL, token_count int NOT NULL,
  summary text                                       -- 可选：LLM 摘要（Agentic 目录用）
);

-- 子块：检索单位
CREATE TABLE chunk (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  tenant_id bigint NOT NULL, kb_id bigint NOT NULL,
  document_id bigint NOT NULL, version_id bigint NOT NULL, section_id bigint NOT NULL,
  ordinal int NOT NULL, kind text NOT NULL CHECK (kind IN ('text','table','list','code','figure_caption')),
  content text NOT NULL,                             -- 原文（展示/重排用）
  search_text text NOT NULL,                         -- 标题路径 + 原文（BM25 用）
  lexical_tokens tsvector,                           -- 仅兼容驱动使用（Go 应用侧 gse 分词，jieba 词典）
  page_start int, page_end int, token_count int NOT NULL,
  is_current boolean NOT NULL DEFAULT false,         -- 当前版本且未禁用
  disabled boolean NOT NULL DEFAULT false,
  access_tags text[] NOT NULL,                       -- 例：{'kb:12:all'} 或 {'u:5','g:9'}
  doc_tags text[] NOT NULL DEFAULT '{}', doc_mime text NOT NULL, doc_updated_at timestamptz NOT NULL
);

-- 向量：一个块在每个嵌入空间一行；不同维度共用一列，按空间建部分索引
CREATE TABLE chunk_vector (
  chunk_id bigint NOT NULL REFERENCES chunk(id) ON DELETE CASCADE,
  space_id bigint NOT NULL REFERENCES embedding_space(id),
  tenant_id bigint NOT NULL, kb_id bigint NOT NULL,
  is_current boolean NOT NULL, access_tags text[] NOT NULL,   -- 与 chunk 同步的过滤字段
  embedding halfvec NOT NULL,
  PRIMARY KEY (chunk_id, space_id)
);
```

## 四、索引

```sql
-- 向量：每个嵌入空间一个部分 HNSW 索引（维度在表达式中固定）
CREATE INDEX CONCURRENTLY chunk_vector_hnsw_s7
  ON chunk_vector USING hnsw ((embedding::halfvec(1024)) halfvec_cosine_ops)
  WITH (m = 16, ef_construction = 64)
  WHERE space_id = 7 AND is_current;

-- 过滤辅助
CREATE INDEX ON chunk_vector USING gin (access_tags) WHERE is_current;
CREATE INDEX ON chunk (version_id, ordinal);
CREATE INDEX ON chunk (section_id);
CREATE INDEX ON chunk USING gin (access_tags) WHERE is_current;

-- BM25（默认驱动 pg_search，Jieba 分词；语法以锁定版本官方文档为准）
-- 需在 M0 验证：中文分词质量、过滤字段（tenant_id、kb_id、is_current、access_tags）能否下推进 BM25 索引扫描
CREATE INDEX chunk_bm25 ON chunk USING bm25 (id, search_text, tenant_id, kb_id, is_current, access_tags, doc_tags)
  WITH (key_field = 'id' /*, search_text 使用 jieba 分词器 */);

-- BM25（兼容驱动）：Go 应用侧分词（gse + jieba 格式词典）后以 'simple' 配置写入 tsvector
CREATE INDEX ON chunk USING gin (lexical_tokens) WHERE is_current;
```

说明：

- 只对 `is_current` 行建部分索引，旧版本块不占热索引；版本切换后旧行由清理任务删除。
- 兼容驱动的 `ts_rank_cd` 不含 IDF，排序质量低于 BM25；它只承担召回，排序依赖后续 RRF 与重排。两驱动均须通过同一检索契约测试与评测门槛（V03）。
- 单个租户块数超过阈值（默认 200 万）时，按 `tenant_id` 列表分区，索引随分区建立。

## 五、RLS 与连接

```sql
ALTER TABLE chunk ENABLE ROW LEVEL SECURITY;
ALTER TABLE chunk FORCE ROW LEVEL SECURITY;
CREATE POLICY tenant_isolation ON chunk
  USING (tenant_id = current_setting('tuskrag.tenant_id')::bigint);
```

- 运行角色 `tuskrag_app`：无 `BYPASSRLS`、非表所有者；迁移角色 `tuskrag_migrator` 单独持有 DDL 权限。
- `tuskrag.tenant_id` 未设置时 `current_setting` 报错 → 请求失败，而不是看到全部数据。
- RLS 只做租户隔离（粗粒度、防编程失误）；知识库角色与文档 ACL 在 SQL 条件 `access_tags && $principal_tags` 中表达，并在出库前复核（[07](07-权限安全与企业治理.md)）。
- 连接池（pgxpool）：api 每实例 10—20 连接，worker 每实例 ≤ 5；超过 3 个 api 实例时前置 PgBouncer（事务模式；`SET LOCAL` 兼容）。

## 六、容量估算

单个子块的热数据（1024 维 halfvec，HNSW m=16）：

| 部分 | 估算 |
|---|---|
| 向量本体 | 1024 × 2 B = 2 KB |
| HNSW 图（第 0 层 2m 个邻居 + 元数据） | 约 0.3—0.5 KB |
| chunk 行（原文约 400 汉字 + search_text + 元数据） | 约 2.5—3.5 KB |
| BM25 索引 | 约 0.5—1 KB |
| **合计** | **约 5.5—7 KB / 块** |

| 规模 | 子块数（约） | 热数据 | 建议 `shared_buffers` | 档位 |
|---|---|---|---|---|
| 5 千篇 × 40 块 | 20 万 | 1.1—1.4 GB | 512 MB（向量索引约 0.5 GB 优先缓存） | lite 2C4G |
| 2.5 万篇 | 100 万 | 5.5—7 GB | 2—3 GB | standard 4C16G |
| 12 万篇 | 500 万 | 27—35 GB | 8—12 GB | 触发 A01 重审 / 分区 |

上表为估算。V08 云端合成实测（2026-10-30，2 CPU、3399 MiB 主机，PG 限额 1536 MiB）：

| 方案 / 块数 | 数据库总大小 | SQL p50 / p95 | 入库 / 建索引 | 越权证据 |
|---|---|---|---|---|
| BM25 v2 + 词典缓存复用 / 20 万 | 1,231,886,003 B（1.147 GiB） | 51.926 / 84.978 ms | 18.976 / 66.315 s | 0 |
| BM25 v2 + 词典缓存复用 / 100 万 | 6,307,542,707 B（5.874 GiB） | 224.084 / 271.923 ms | 152.705 / 440.711 s | 0 |

5 次预热后测 100 次；一个合成文档复用 256 种 1024 维向量，不包含模型调用，不是上表多文档规模或并发负载的验收。两种规模的 PG 采样内存峰值分别为 1179.65 / 1220.61 MiB；20 万块达到 100 ms SQL 预算，百万块未达到。最终测试无并行诊断负载，见 [原始数据与测量边界](eval-reports/2026-10-30-sql-capacity.md)。旧的 20 万块基线 p95 为 833.479 ms。

若需进一步压缩：向量降维（如 bge-m3 Matryoshka 不适用时不得强降）或 `binary_quantize` 粗召回 + 原向量重算，均须通过评测门槛。

## 七、文件存储

- 驱动接口 `FileStore.put/get/delete/exists`，键：`t/{tenant}/kb/{kb}/d/{doc}/v/{version}/original`。
- 默认 `local`（挂载卷）；可选 `s3`（企业已有 OSS/COS/MinIO 等兼容服务）。
- `local` 以同目录临时文件写入并同步内容，再通过硬链接原子发布不可覆盖的版本；挂载卷必须支持硬链接。进程中断可能留下临时文件，发布后的清理错误须结合数据库状态核对，不得盲目覆盖已有原件。
- 原件写入成功后才提交 `document_version`；删除走清理任务，PG 先标记、文件后删除，失败可重试。
- 备份需与 PG 备份成对执行并校验引用一致性（[09](09-部署运维与可观测.md#四备份与恢复)）。

## 八、任务队列

```sql
CREATE TABLE job (
  id bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  tenant_id bigint NOT NULL, kind text NOT NULL,          -- ingest | reembed | purge | eval_run | acl_refresh
  dedupe_key text, payload jsonb NOT NULL,
  status text NOT NULL CHECK (status IN ('queued','running','succeeded','failed','dead','cancelled')),
  attempts int NOT NULL DEFAULT 0, max_attempts int NOT NULL DEFAULT 3,
  run_after timestamptz NOT NULL DEFAULT now(),
  lease_owner text, lease_until timestamptz, lease_generation int NOT NULL DEFAULT 0,
  last_error text, created_at timestamptz NOT NULL DEFAULT now(), finished_at timestamptz
);
CREATE UNIQUE INDEX ON job (tenant_id, kind, dedupe_key)
  WHERE dedupe_key IS NOT NULL AND status IN ('queued','running');
CREATE INDEX ON job (tenant_id, run_after) WHERE status = 'queued';
```

- 认领：`SELECT ... FOR UPDATE SKIP LOCKED LIMIT 1` 并写入租约；`NOTIFY job_ready` 唤醒空闲 worker，轮询兜底间隔 5 s。
- 租约续期；过期由其他 worker 重新认领并 `lease_generation + 1`；提交结果时校验世代，迟到结果被拒绝。
- 重试只针对可恢复错误（网络、429、5xx），指数退避且有上限；解析失败类错误（格式损坏、超限）直接失败，不重试。
- 队列实现选择见 [A12](11-架构决策记录.md#a12)；上述语义是验收契约。

## 九、缓存

| 缓存 | 位置 | 可丢失 | 失效 |
|---|---|---|---|
| 查询嵌入缓存 | `UNLOGGED` 表 `query_embedding_cache(space_id, query_hash, embedding, expires_at)` | 是 | TTL 7 天；空间切换即不命中 |
| 主体 principal tags | api 进程内 LRU，TTL ≤ 30 s | 是 | 组/成员/ACL 变更通过 `NOTIFY acl_changed` 清除 |
| 检索结果 | 不缓存 | — | 权限与版本变化频繁，缓存收益不抵正确性风险 |
