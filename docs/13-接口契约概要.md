# 13 接口契约概要

本文给出接口形状与约束；已实现的 REST 与 SSE 字段以 `contracts/openapi.json`（由 Go 核心经 huma 从类型生成并提交）为准，解析输出以 `contracts/parsed-document.schema.json` 为准。本文的 MCP、Agentic 和其他未标明已实现的规划接口不代表可用能力。版本前缀 `/api/v1`。

约定：游标分页 `?cursor=&limit=`；写操作支持 `Idempotency-Key` 头（上传、创建、评测运行）；并发修改用 `If-Match` 修订号，冲突返回 409。

评测运行 GET 返回 `id/job_id/set/mode/status/attempts/max_attempts/failure_code/result_available/created_at/finished_at`；status 为 queued/running/succeeded/failed/dead/cancelled，failure_code 为最近失败代码（重试后保留的历史错误不改变当前 status），无代码或完成时间时为 null。不返回完整运行配置或题目。只有已提交的成功结果才有 result_available=true，且返回前复核报告全部实际证据；任务成功但无结果等内部不一致返回 500，不能伪造可用结果。

运行历史列表 GET 使用非负 cursor（默认 0）、limit 1—10（默认 10），按运行 ID 升序返回 `{items: RunStatus[],next_cursor: number|null}`。SQL 在分页前过滤失效的完整允许范围、固定修订目标及已提交结果的全部实际证据；随后连同下一页探测项统一加锁并复核。失效记录不造成虚假空页或下一页提示；读取期间撤权则整页失败，包括空页。列表不要求运行创建者仍有权限，按当前读取者校验，归档允许读取；无总数，不返回题目或完整配置。新运行可从首页重新分页查看。控制台 `/kb/$kbId/eval/history` 已接入游标分页、显式刷新与运行详情跳转，见[历史页面验收](eval-reports/2026-11-06-eval-history-ui.md)。

`/result` 返回与报告读取相同的 `{digest,source,created_at,report}`，但来源固定 executed，与导入的 imported 区分。合法可见运行尚无成功结果时返回 409 `result_unavailable`，调用方通过状态接口区分进行中、失败与取消，不把该错误当作空报告。无权、跨知识库/租户、未知运行或失效目标/证据返回 404，普通成员返回 403；归档允许读取。状态、结果及“无结果”响应都先按当前读取者复核，响应 no-store，GET 无须 CSRF。控制台已接入固定修订运行、状态轮询与 executed 报告展示，见[运行页面验收](eval-reports/2026-11-06-eval-run-ui.md)。

两次服务端运行对比 GET `eval-run-comparison?baseline=<run_id>&current=<run_id>&offset=0&limit=20`，运行 ID 必须为正；offset 0—10000，limit 1—50。返回 `{baseline_run_id,current_run_id,source:"executed",comparison}`，comparison 复用报告比较结构，摘要对应实际已提交报告。差值为当前减基线；按题号对齐，完整定义摘要、模式、模型类型及题目总体必须可比，否则 409 reports_incomparable。超过两百分点回退返回成功响应中的 regressed 门禁，不当作 HTTP 错误。

对比在同一事务合并两次运行的完整允许范围及全部实际证据，按当前读取者锁定复核后才计算指标与裁剪逐题页；未返回页的证据失效也拒绝整份对比。缺少成功结果仍先完成两侧权限复核，可见时返回 409 result_unavailable；未知、跨库或失效证据返回 404，普通成员 403，存储报告损坏 500。归档允许比较，当前配置变更不抹去历史结果。GET 无 CSRF、响应 no-store，不混入 imported 报告；控制台已从运行历史接入两次运行选择、方向交换与逐题差异分页，见[运行对比页面](eval-reports/2026-11-06-run-comparison-ui.md)。

创建 POST 仅接受 `{set_id,revision,mode}`：题集与修订必须为正整数，模式为 lexical/vector/rrf/rerank。必须提供 CSRF 和 1—128 个可见 ASCII 字符的 Idempotency-Key；成功返回 200 `{id,job_id}`，不推断当前任务状态。主体来自会话；服务端捕获当前可见、继承知识库权限且当前版本 ready/partial 的完整文档范围，以及嵌入绑定和检索修订。超过 10000 个文档返回 422 evaluation_scope_too_large。rerank 使用已保存的重排配置并禁用降级；未配置返回 409 rerank_unavailable。其他模式显式不启用重排。模型标签由服务端生成，real 表示配置的运行路径，不证明模型端权重。

创建幂等键绑定知识库、用户和原始请求；同键同请求在配置或新增文档后仍返回原运行，同键不同请求返回 409 idempotency_conflict。重试仍复核原范围和当前权限，归档返回 409 knowledge_base_archived。首次创建的配置竞争返回 409 configuration_changed；不可见或失效题集目标返回 404。记录、任务、审计与幂等结果同事务提交。快照不冻结文档版本、提供方连接配置或模型端权重。

评测集 POST/PUT 接收 [SetDefinition](../tests/eval/README.md#知识库评测集定义校验)，返回 `200 {id,revision,digest,created_at,definition}` 和强 `ETag: "<revision>"`，写请求要求 CSRF。POST 可带 1—128 个可打印 ASCII 字符的 `Idempotency-Key`：相同主体、知识库、键和规范化内容重试返回原始第 1 修订，不重复审计；内容不同返回 409 `idempotency_conflict`。省略键时每次创建独立题集。PUT 全量替换定义，必须携带精确强 `If-Match`；过时修订返回 409 `revision_conflict`，不接受通配、弱标签或列表。GET `?revision=0`（默认）读取当前快照，正整数读取指定历史修订；历史不可变，但仍按当前权限复核。

题集存取要求 owner/admin；普通成员 403、跨租户/知识库、无成员、未知题集/修订或不可见期望位置均为 404。每个期望项须在当前 ready/partial 文档版本中有一个可见、未禁用且符合节/页约束的块；任一项失败则整份拒绝，不返回部分题目。所有无答案题的题集不需要文档证据，但仍检查成员。先按文档、知识库、成员、证据顺序加锁，保存修订、切换头指针、审计及创建幂等记录在同一事务。归档只读；重试创建也重查权限和位置。管理员可用已知修订号全量替换失效定义，替换操作只验证新定义，不返回旧正文。存取不执行评测；控制台已支持题集列表、创建、逐题编辑和修订冲突处理，见[页面验收](eval-reports/2026-11-06-eval-set-ui.md)；批量运行仍待实现。验收见[题集存取](eval-reports/2026-11-06-eval-set-storage.md)。

题集列表 `GET /api/v1/kbs/{kb}/eval-sets?cursor=0&limit=10` 返回 `{items,next_cursor}`。按题集 ID 升序分页，cursor 为非负 ID，limit 为 1—10；每项仅含 `id/revision/digest/name/case_count/created_at`，来自查询时的当前修订，不返回题目或参考答案。SQL 在分页前过滤任一期望位置不可见的题集；返回前合并整页及下一页探测项的目标加锁复核，空页仍复核成员。无后续可见记录时 next_cursor 为 null，否则取当前页最后一项 ID；不返回隐藏题集数量或游标。并发撤权或位置失效显式失败；刷新从 cursor=0 开始，已翻页题集的新修订不会重复插入后续页。见[列表验收](eval-reports/2026-11-06-eval-set-list.md)。

评测报告导入体为 CLI `eval run` 的完整成功报告，要求 CSRF，响应 `200 {digest, source, created_at, report}`，其中 `source=imported` 明确表示外部导入，不证明服务端执行过该评测。按规范化 JSON 的 SHA-256 在当前租户/知识库内去重，相同报告重试返回同一记录且不重复写审计。上限为 8 MiB、10,000 题、每题每份候选列表 100 条、10,000 个不同块。校验逻辑见[完整报告校验](../tests/eval/README.md#完整报告校验)。无答案指标为 null，延迟分位数必须是两个数字，不能为 null。

导入与读取均要求当前 owner/admin；普通成员返回 403，跨租户或无成员返回 404。逐个核对所有证据块的知识库、文档、节和页范围，且要求当前版本、未删除、继承知识库权限、块未禁用及知识库访问标签；任一证据不可见则整份报告返回 404，不截断成部分成功。归档拒绝导入（409），仍可读取满足证据条件的报告。保存与审计同事务，应用角色不能修改/删除历史报告。存取不改变检索配置或执行模型；报告页面已接入导入、列表、指标及逐题查看，见[页面验收](eval-reports/2026-11-06-evaluation-ui.md)；题集编辑与固定修订批量运行页面已接入。

报告列表 `GET /api/v1/kbs/{kb}/eval-reports?cursor=&limit=10` 返回 `{items,next_cursor}`，每项包含摘要标识、来源、保存时间、数据集版本、模型标记/类别、检索模式与汇总指标，不返回逐题证据。limit 为 1—10，按 digest 升序稳定分页；下一页游标只取当前页最后一个可见报告的 digest，无后续可见结果时为 null。SQL 在分页前排除任一证据失效的报告，不返回隐藏报告计数或游标；返回前按整页证据加锁复核，竞态失效或撤权显式失败，客户端应刷新。新增报告可能排在已有游标之前，刷新需从空游标开始。验收见[报告列表](eval-reports/2026-11-06-report-list.md)。

报告对比查询参数为 `baseline=<digest>&current=<digest>&offset=0&limit=20`，limit 为 1—50，offset 为 0—10000。仅比较同知识库的完整报告，要求数据集 SHA-256、检索模式、模型类别、题数及有答案题数一致，至少含一道有答案题，并按题号校验题集和每题答案属性一致；不要求两份数组顺序相同。不可比返回 409 `reports_incomparable`，权限和证据错误沿用报告读取契约。两份报告全部证据在同一事务内复核，包含请求页外证据。

成功响应包含两份摘要标识、基线/当前汇总、`delta`、`gate`、逐题 `rows`、`total_rows` 和可空 `next_offset`。差值一律为当前减基线，允许负数；任一汇总指标下降超过两百分点（浮点容差 1e-12）时 `gate=regressed`，仍返回 HTTP 200，不丢弃差异。每题包含基线/当前结果、可空指标差值和证据顺序/位置是否改变；无答案题的 delta 为 null。题目按基线顺序分页。当前报告均为外部导入，对比门禁不证明模型质量；两次报告对比页面已接入报告选择、方向交换、汇总差值与逐题分页，URL 保留选择和分页；不可比时保留选择入口，撤权时隐藏结果与列表，见[页面验收](eval-reports/2026-11-06-comparison-ui.md)。

当前本地登录返回租户 ID、用户 ID 与 `csrf_token`，会话令牌只写入 HttpOnly Cookie；`GET /api/v1/me` 可恢复 CSRF 值。会话写请求必须携带 `X-CSRF-Token`。登录请求必须携带自定义头，服务端不允许跨域预检，从而阻止跨站表单登录。

当前文档列表支持 `cursor` 和 `limit` 分页，返回 `next_cursor`、当前生效版本和最新版本状态；仅返回继承知识库权限的文档。状态、标签和文本过滤及文档级 ACL 尚未接入。

`GET /api/v1/documents/{doc}/toc` 分页返回当前版本的节、父节、标题路径和页范围；`GET /api/v1/sections/{id}` 返回当前版本的单节 Markdown。仅数字 PDF 的页码标为物理页；其他格式返回空页码。读取前锁定文档、成员和当前版本并核验全部块，遇到受限或禁用块时拒绝整份文档的目录与正文读取；超过限额显式失败。读取写入不含正文的审计记录，见[章节读取对照](eval-reports/2026-10-29-section-reading.md)。

当前上传接口接收一个名为 `file` 的 multipart 文件，按文件扩展名选择受支持的解析类型；可用 `allow_duplicate=true` 显式允许重复内容，并支持 `Idempotency-Key`。设置 `confirm_first_row_headers=true` 表示用户确认该文件中所有表格的首行均为表头，选择随版本固定；CSV、DOCX、XLSX 和数字 PDF 的未确认表格会明确失败。请求返回文档、版本和当前状态；工作进程可处理的格式及限制见[格式支持矩阵](05-文档解析与入库.md#二格式支持矩阵)，入队不表示处理成功。文件上限 200 MiB，未配置原件存储时上传返回 503。

重新上传保留文档标题和格式，返回新的版本编号；处理失败不影响生效版本。相同原件可在表头确认决定改变时生成新版本；同一文档中原件与确认决定均相同的版本不能重复创建。跨文档重复仍须显式设置 `allow_duplicate=true`。当前仅支持继承知识库权限的文档，见[版本更新对照](eval-reports/2026-10-28-version-upload.md)。

删除返回 `202 {"status":"deleting"}`，表示文档已从列表和检索中隐藏，原件与版本数据由后台任务清理；不表示清理已完成。每次最多处理 10,000 个版本，失败时事务回滚。当前仅支持继承知识库权限的文档，见[删除对照](eval-reports/2026-10-28-document-deletion.md)。

当前任务接口仅支持文档入库任务：编辑者可用 `GET /api/v1/jobs/{id}` 查看状态、尝试次数和能否重试，文档列表为编辑者提供最新任务编号与 `retryable`。`POST /api/v1/jobs/{id}:retry` 为可恢复且已进入死信的最新版本创建新任务，返回 202、任务编号和 `queued`；原任务及其失败原因保留。仅模型、存储、索引暂不可用、超时和租约耗尽可手动重试，文件损坏、加密、表头未确认等需处理原文件或配置。排队不表示已完成。实现与测试边界见[任务重试对照](eval-reports/2026-10-29-job-retry.md)。

知识库配置已交付检索参数的存取与消费子功能（R01/R06/R13，M1）：`GET /api/v1/kbs/{kb}/config` 返回 `revision`、可选 `retrieval` 与强 ETag；修订 0 且无 `retrieval` 表示尚未保存。owner/admin 可读写，其他成员返回 403，不可见知识库返回 404。`PUT` 要求 CSRF 和 GET 返回的原样 `If-Match`（例如 `"0"`），提交 `{"retrieval":{"top_k":8}}`；可选 `reranker` 结构复用检索请求的提供方、模型、Top-N、降级与阈值字段，省略代表关闭重排。PUT 替换整份检索参数并追加修订；旧修订返回 409 `revision_conflict`，归档知识库拒绝写入。提供方必须属于当前租户并符合当前出域策略；保存不调用模型，也不证明模型可用。检索修订与入库修订的区别见 A09。

保存的配置已接入检索默认值。控制台默认使用知识库配置，也可单次关闭或自定义重排，并显示本次读取的检索配置修订。owner/admin 可展开配置表单读取和保存默认值；并发冲突保留输入，显式载入最新修订后再编辑；归档只读，撤权后隐藏表单。模型提供方填写平台管理员提供的编号，不依赖平台管理列表权限；不存在或异租户编号返回 404 `provider_not_found`，允许更正输入。分块配置和历史查询接口尚未实现。表单验收见[配置编辑报告](eval-reports/2026-11-06-config-editor.md)。

### 检索请求与响应（摘要）

当前仅支持一个 `kb_id` 和继承知识库权限的文档。省略 `top_k` 时使用已保存值，未配置时为 8；显式值覆盖默认值。省略重排选项时继承知识库设置，未配置时返回带 `degraded: ["rerank"]` 的 RRF 结果。显式 `options.rerank=false` 关闭重排；显式 `options.reranker` 整体覆盖已保存的重排设置（`provider_id`、`model`，可选 `top_n=20/30/50`、`fallback`、`min_score`）。`rerank=false` 与 `reranker` 同传返回 400；`rerank=true` 但请求和知识库均无模型配置时返回 503 `rerank_unavailable`。成功重排分数为 `score_kind: "rerank"`；失败按[检索流水线](06-检索与问答.md#二检索流水线)规定处理。`options.debug=true` 返回当前权限下的候选排名、分数、过滤条件、降级标志及阶段耗时；BM25/向量/RRF 共用一次 SQL，耗时合并为 `recall_rrf`，不伪造独立阶段计时。每次请求在当前成员权限下读取不可变配置快照，释放事务后再调用模型；修改配置影响下一请求，在途请求不混用新旧设置。响应及调试 trace 的 `retrieval_revision` 记录读取的检索修订（未配置为 0，即使参数被请求覆盖也保留所读修订），不是入库 `config_revision`。成员权限、证据和出域策略仍按当前状态复核。父节扩展仍返回不支持错误。契约以生成的 `contracts/openapi.json` 为准，验证见[重排与评测报告](eval-reports/2026-10-29-m1.md)。

```jsonc
// POST /api/v1/search
{ "query": "差旅住宿标准", "kb_ids": [12], "top_k": 8,
  "filters": { "doc_tags": ["制度"], "updated_after": "2026-01-01" },
  "options": { "rerank": false, "expand_parent": false } }

// 200
{ "status": "ok",                     // ok | no_match
  "degraded": ["rerank"],             // 向量降级尚未实现
  "evidence": [ { "id": "c_123", "score": 0.032, "score_kind": "rrf", "content": "...",
      "document": { "id": 45, "title": "差旅管理办法", "version_id": 77 },
      "section": { "id": 901, "heading_path": ["第三章 住宿", "3.2 标准"] },
      "pages": [5, 6] } ],
  "trace_id": "..." }
```

`no_match` 表示在**可见范围内**没有达到阈值的证据；它不揭示是否存在不可见的匹配。

## 二、SSE 事件

| 事件 | 数据 | 说明 |
|---|---|---|
| `retrieval` | `{evidence: AnswerEvidence[],degraded: string[],retrieval_revision}` | 生成前发送；证据包含编号、原文、文档/版本/节及 PDF 页码 |
| `step` | Agentic 模式的工具调用摘要（工具名、参数摘要、结果数） | 仅 agentic |
| `delta` | `{ "text": "..." }` | 文本增量 |
| `citations` | `{items:[{n:1,evidence_id:"c_123"}],invalid_count}` | 生成结束后校验结果 |
| `done` | `{message_id,outcome,prompt_version,usage?}` | outcome 为 answered/refused/unsupported/truncated；仅完整终态 |
| `error` | `{ "code", "message", "retryable" }` | 异常结束；之后不再有事件 |

心跳：每 15 s 发送注释行；客户端断开即取消上游 LLM 请求。

已实现的单轮请求为 `{kb_id,model_id,question}`，需要当前会话及 `X-CSRF-Token`；问题最多 4,096 UTF-8 字节，请求体最多 16 KiB。模型列表不返回地址与凭据；模型创建为 `{name,base_url,locality,model,api_key?}`，external 要求 HTTPS。直接 `/answers` 的 `message_id` 仅是本次生成标识；会话消息的 ID 对应数据库记录。正常序列为 retrieval → delta* → citations → done；任意阶段可转 error，未收到终态的 EOF 视为中断。客户端必须丢弃错误/取消后的部分结果，不把不可复核的证据继续展示。

当前 SSE 错误包括 `evidence_unavailable`、`unauthenticated`、`timeout`、`cancelled`、`egress_denied`、`model_invalid_response`、`model_unavailable`、`configuration_changed` 和 `internal_error`。建立流后错误通过事件返回；生成不自动重试。`step` 仅为 Agentic 规划，当前服务不发送。

会话创建为 `{kb_id,model_id,title}`，固定知识库与模型；标题最多 120 字符。列表按 ID 倒序每页 20 项，`cursor=0` 为首页，返回 `{items,next_cursor}`；只返回当前用户的会话。读取返回 `{conversation,messages}`，每条包含问题、完成正文、证据、引用、降级、终态、可选反馈和时间。全部历史证据失效时返回 409 `evidence_unavailable`；撤权或他人会话返回 404。不会以裁剪旧答案掩盖证据失效。

会话消息 POST 只接受 `{question}`，不接受客户端提供历史。每会话最多 50 轮、同时只能有一轮在生成；冲突通过 `conversation_busy` / `conversation_full` SSE 事件返回。流式增量写入 PG 的短事务，完成后才公开正文；取消、失败及超过 125 秒的遗留运行清除部分正文和证据，保留失败状态。刷新可恢复完成消息；未完成消息不当作模型回答。

反馈 POST 为 `{rating:1|-1,correction:""}`，纠错最多 4,000 UTF-8 字节；仅本人已完成且全部证据仍有效的消息可写。按消息覆盖本人上次反馈，返回 `{status:"pending"}`，审计只记录标识。当前已保存到待审池，尚无审核管理页面。控制台 URL 使用 `?conversation=<id>` 恢复选择。

## 三、MCP 工具

与 [06 第七节](06-检索与问答.md#七agentic-模式与-mcp-工具) 一致：`search`、`list_documents`、`get_toc`、`read_section`、`get_neighbors`。工具只读；输入 schema 与 REST 共用同一组 Go 类型；输出包含 `citation`（文档标题、版本、节路径、页码）字段，便于外部 Agent 引用。

## 四、错误模型

```json
{ "error": { "code": "model_unavailable", "message": "重排服务超时", "retryable": true, "trace_id": "..." } }
```

| HTTP | code 示例 | 语义 |
|---|---|---|
| 400 | `invalid_request`、`unsupported_format`、`limit_exceeded` | 输入不合法；不重试 |
| 401 | `unauthenticated` | 未登录或 Key 无效 |
| 403 | `forbidden` | 已知对象上的动作无权限（仅用于主体可见的对象） |
| 404 | `not_found` | 对象不存在**或不可见** |
| 409 | `revision_conflict`、`duplicate_content` | 并发修改或重复内容 |
| 422 | `egress_denied` | 出域策略禁止所需的模型调用 |
| 429 | `rate_limited`、`quota_exceeded` | 带 `Retry-After` 与配额类型 |
| 503 | `model_unavailable`、`dependency_unavailable` | 外部依赖失败；`retryable=true` |
| 500 | `internal` | 未预期错误；只返回 trace_id |

规则：不使用 200 + 空结果表示失败；降级成功使用 200 + `degraded`；所有错误均带 `trace_id`，日志中可关联。


### 已实现的嵌入重建接口（T13）

创建 POST 仅接受 `{target_space_id,revision}`，分别为正目标空间 ID 和当前知识库 config_revision（1—2147483646）。要求会话、CSRF、1—128 个可见 ASCII 字符的 Idempotency-Key，正文最多 4096 字节；成功返回 200 的 Rebuild 任务快照。同键重试与源空间保持规则见 [04](04-数据模型与存储.md)，排队不代表切换成功。并发重建返回 409 rebuild_in_progress，源修订冲突 409 revision_conflict，异请求重用键 409 idempotency_conflict；不支持的目标 422 unsupported_embedding，出域拒绝 422 egress_denied。

GET 返回 job_id、源空间/修订、目标空间、六类任务状态、尝试次数及上限、失败码和创建/完成时间；failure_code 与 finished_at 明确可为 null。failure_code 是队列最后一次失败记录，重试成功后也可保留；当前结果以 status 为准。取消 POST 不需要请求体，要求 CSRF，成功返回 200 `{status:"cancelled"}`；已终态或不可取消任务返回 404。GET 和取消允许归档知识库，创建归档知识库返回 409 knowledge_base_archived。主体只取会话；当前 owner/admin 授权由领域事务复核，不可见/跨租户对象 404，权限不足 403。控制台入口仍待接入。
