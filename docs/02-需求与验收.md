# 02 需求与验收

优先级：P0 = M1/M2 必须；P1 = M3/M4 必须；P2 = 有评测或客户证据后进入。里程碑定义见 [12](12-开发计划与里程碑.md)。

## 一、功能需求

| 编号 | 需求 | 关键规则 | 优先级 | 里程碑 |
|---|---|---|---|---|
| R01 | 租户与知识库管理 | 创建/归档知识库；每个知识库绑定且仅绑定一个嵌入空间；配置分块与检索参数并版本化 | P0 | M1 |
| R02 | 文档导入 | 单个/批量上传；静态 URL 导入；按 SHA-256 在知识库内去重；大小、页数、压缩比上限可配置 | P0 | M1 |
| R03 | 分层解析 | 原生解析优先；逐页质量评分；不达标页按策略走 VLM；产出页级解析报告；不支持的格式显式拒绝 | P0（原生）/P1（VLM） | M1/M4 |
| R04 | 结构化分块 | 按标题树生成节；节内生成子块并携带标题路径；表格整体或带表头切分；块可预览、可禁用 | P0 | M1 |
| R05 | 版本与增量 | 重新上传生成新版本；新版本就绪后原子切换；删除先软删除再清理；失败版本不影响当前版本 | P0 | M1 |
| R06 | 混合检索 | 过滤（知识库、标签、时间、文档类型）+ BM25 + 向量 → RRF → 重排；参数可按知识库配置 | P0 | M1 |
| R07 | 上下文组装 | 父节回溯、相邻块合并、去重、按 token 预算打包，保留页码与节定位 | P0 | M2 |
| R08 | 问答与引用 | SSE 流式输出；回答中的引用必须对应已提供证据；证据不足时拒答；多轮问题改写 | P0 | M2 |
| R09 | Agent 接入 | 检索 REST API；MCP 工具（search、list_documents、get_toc、read_section、get_neighbors）；可选 Agentic 问答模式 | P1 | M4 |
| R10 | 检索调试台 | 展示每阶段候选（BM25、向量、RRF、重排）的分数与排名、过滤条件、耗时 | P0 | M1 |
| R11 | 评测与反馈 | 评测集管理、批量运行、指标对比；用户点赞/点踩与纠错进入待审池 | P0（离线评测）/P1（反馈） | M1/M2 |
| R12 | 身份与单点登录 | 本地账号（仅初始化与应急）+ 通用 OIDC；用户组来自 OIDC 声明或手工维护 | P1 | M3 |
| R13 | 权限 | 租户隔离；知识库角色 owner/admin/editor/viewer；文档级 ACL；检索前过滤 + 出库复核；撤权即时生效 | P0（租户与知识库角色）/P1（文档 ACL） | M1/M3 |
| R14 | API Key 与配额 | Key 绑定租户、主体与范围（知识库 + 动作）；只存哈希；限速与月度 token 配额 | P1 | M3 |
| R15 | 审计 | 追加写；记录管理操作、检索与原文读取的主体、对象、结果摘要；不记录正文 | P1 | M3 |
| R16 | 模型与数据出域 | 模型提供方配置（LLM、嵌入、重排、VLM）；知识库级数据出域策略；更换嵌入模型触发重建 | P0（提供方）/P1（出域策略） | M1/M3 |
| R17 | 运维 | 存活/就绪检查；指标；结构化日志；备份恢复；向前迁移；后台任务可见与可重试 | P1 | M5 |

## 二、非功能需求

| 编号 | 需求 | 目标 |
|---|---|---|
| R18 | 资源预算 | 满足 [01 第三节](01-定位与范围.md#三量化目标目标值待测量) 的内存与服务数目标 |
| R19 | 性能 | 满足 [01 第三节](01-定位与范围.md#三量化目标目标值待测量) 的延迟与吞吐目标 |
| R20 | 可靠性 | 后台任务崩溃可恢复、幂等；外部模型失败显式暴露；不返回伪成功或空结果冒充“无匹配” |
| R21 | 安全 | 不可信文件在受限子进程解析；密钥加密存储；日志不含正文与完整 Prompt |
| R22 | 可移植 | 自建 PG 镜像为默认；托管 PG 通过兼容驱动运行（功能降级须在启动时声明）；支持完全离线部署 |

## 三、验收场景（T）

每个场景须给出可复现步骤与证据；“文档检查”不算产品验收。

| 编号 | 场景 | 通过标准 | 关联 |
|---|---|---|---|
| T01 | 上传 DOCX、数字 PDF、XLSX、Markdown 各 1 份 | 均达到“可检索”；解析报告显示标题树、表格数、页数；表格结构以 Markdown 表保留 | R02—R04 |
| T02 | 上传扫描 PDF，出域策略“禁止” | 质量门判定低分页；不调用外部 VLM；文档状态为“部分可用/需处理”，并提示原因 | R03、R16 |
| T03 | 同一扫描 PDF，出域策略“允许” | 仅低分页调用 VLM；报告列出 VLM 页与费用估计；结果可检索 | R03 |
| T04 | 重新上传同名文档的修订版 | 新版本就绪前检索仍命中旧版本；就绪后只命中新版本；无混合结果 | R05 |
| T05 | 同时提问“精确条款号”与“语义改写”问题 | 前者由 BM25 命中，后者由向量命中；调试台显示各阶段排名 | R06、R10 |
| T06 | 问答命中跨页表格内容 | 回答引用指向正确的文档、页码与节；点击引用可定位原文 | R07、R08 |
| T07 | 问知识库中不存在的问题 | 返回拒答，不编造引用 | R08 |
| T08 | 用户 A 无权访问文档 D | 检索、问答、MCP、调试台均不出现 D 的任何内容、标题或计数 | R13 |
| T09 | 撤销用户 A 对知识库的权限 | 下一次请求即被拒绝；进行中的流式回答不再返回新证据 | R13 |
| T10 | 租户 X 的 API Key 访问租户 Y 的知识库 | 返回 404（不暴露存在性），审计记录拒绝 | R13—R15 |
| T11 | 外部 Agent 通过 MCP 完成“查目录→读节→回答” | 工具结果带引用定位，权限与 T08 一致 | R09 |
| T12 | 运行评测集并对比两次配置 | 输出 Recall@k、MRR、nDCG、引用准确率、拒答准确率及差异 | R11 |
| T13 | 更换知识库嵌入模型 | 后台重建新嵌入空间；完成前继续使用旧空间；完成后原子切换 | R16、R05 |
| T14 | 入库过程中强杀 worker | 重启后任务被重新认领，最终状态正确且无重复块 | R20 |
| T15 | 外部重排服务超时 | 按配置显式失败或返回“未重排”标记的结果；不静默伪装为重排结果 | R20、R06 |
| T16 | 备份后删除库再恢复 | 文档、版本、块、向量、文件、权限与审计一致；检索结果与备份前相同 | R17 |
| T17 | lite 档位资源测量 | 空载与入库峰值内存、检索延迟满足 R18/R19 或给出偏差报告 | R18、R19 |
| T18 | 上传 zip 炸弹 / 超大 XML 实体 / 加密 PDF | 被拒绝或超限终止，worker 主进程不受影响 | R21 |
| T19 | 使用托管 PG（无 pg_search）启动 | 启动日志声明兼容驱动及降级项；兼容驱动通过同一契约测试 | R22 |
| T20 | OIDC 登录并按组授权 | 组成员变化在下次登录或同步后生效；本地应急账号可审计 | R12、R13 |

## 四、需求追踪

- 每个 PR 关联至少一个 R 或 A 编号；行为变更同时关联 T 或 V。
- 需求冲突时先在本文档记录变更与理由，再修改实现；不默默降低验收标准。
